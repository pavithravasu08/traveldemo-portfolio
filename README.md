# 🌍 TravelDemo – Travel Website Portfolio

TravelDemo is a responsive travel website created as a **front-end portfolio project** using HTML and CSS.

The website is designed to showcase travel destinations, popular places, travel interests, and trip inspiration through a simple and user-friendly interface.

## ✨ Features

* 🏠 Home page with travel-focused hero section
* 🔎 Search interface
* 🌴 Travel destination categories
* 🏖️ Popular destination cards
* 🍴 Travel interests and experiences
* 💡 Travel inspiration section
* 📩 Contact form
* 📱 Responsive design for desktop, tablet, and mobile
* 🎨 Modern layout using CSS Grid and Flexbox
* ✨ Hover effects and interactive navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* Google Fonts
* Responsive Web Design

## 🎯 Purpose of the Project

This project was created to practice and demonstrate front-end development skills, including:

* Creating semantic HTML structures
* Styling websites using CSS
* Using Flexbox and CSS Grid
* Creating responsive layouts
* Designing navigation menus
* Creating cards and sections
* Working with images
* Adding hover effects
* Creating forms
* Building a complete multi-section website

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation or setup is required.
