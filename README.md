## Tripadvisor Clone 🌍

A responsive **Tripadvisor Clone website** created using **HTML and CSS**. This project recreates the basic layout and design of Tripadvisor, including a navigation header, search section, destination cards, activity categories, Chennai experience recommendations, travel inspiration, and footer sections.

### Features

* Responsive Tripadvisor-style navigation bar
* Search and category section
* Destination image cards
* Things-to-do promotional section
* Interest-based activity categories
* Chennai experience recommendations
* Popular destination inspiration section
* Responsive design for desktop, tablet, and mobile
* Hover effects and horizontal scrolling cards

### Technologies Used

* HTML5
* CSS3

### Purpose

This project was developed as a **frontend practice project** to improve skills in HTML structure, CSS styling, Flexbox, responsive design, positioning, image cards, and website layout development.
